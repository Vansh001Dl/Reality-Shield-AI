# Project UI requirement

- Do not show fabricated dashboard analysis before a user uploads and successfully analyzes a video.
- Before analysis, show neutral placeholders and explain that results are waiting for a video. This applies to risk scores, SHAP factors, object counts, alerts, weather, location, road conditions, and route recommendations.
- Populate those modules only from the uploaded video and its API responses. Keep system and backend health indicators separate from video analysis results.
